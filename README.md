# Python Konsol Menüsü

Temel algoritma alıştırmalarını tek bir Tkinter penceresinde toplayan ödev projesi. Soldaki butona tıklanınca gerekli girdiler küçük pencerelerle sorulur, sonuç sağ tarafta gösterilir.

Betül Canol ve Hatice Reyhan Çalışkan.

## İçindeki fonksiyonlar

| # | Buton | Ne yapar |
|---|---|---|
| 1 | Xth Smallest Element | Listedeki x. en küçük elemanı bulur |
| 2 | Closest Pairs to X | Toplamı x'e en yakın olan sayı çiftini bulur |
| 3 | Repeating Elements in a List | Listede birden fazla geçen elemanları listeler |
| 4 | Matrix Multiplication | İki matrisi çarpar |
| 5 | Word Frequency | Bir metin dosyasındaki kelimelerin kaç kez geçtiğini sayar |
| 6 | Smallest Value in a List | En küçük değeri özyinelemeli olarak bulur |
| 7 | Babylon Square Root | Babil yöntemiyle karekök hesaplar (tolerans 1e-10, en fazla 10 iterasyon) |
| 8 | Greatest Common Divisor | Öklid algoritmasıyla EBOB |
| 9 | Prime Number Checker | Sayının asal olup olmadığını kontrol eder |
| 10 | Faster Fibonacci | Bilinen F(k) ve F(k-1) değerlerinden başlayarak F(n)'i hesaplar |

## Çalıştırma

```bash
python "Proje odevi 1.py"
```

Sadece standart kütüphane (Tkinter) kullanılıyor.
